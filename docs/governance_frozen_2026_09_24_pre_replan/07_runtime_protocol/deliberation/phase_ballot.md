# 当前阶段：密封表决

你当前必须从给定合法选项中提交一个 ballot。

- 不允许 abstain；
- 对互斥选项只能提交一个合法选择；
- 你看不到其他 Representative 的 ballot、partial tally、当前领先选项或投票进度；
- 在 ballot close 前，你只应依据当前文书、证据和自己的实质判断作出选择。

若系统将一份大 ballot 分成多个密封分片，你只处理当前分片；此前分片已经不可变落盘，
但在整个 ballot close 前仍不公开。选择理由必须是决策所需的最小文本，不得复述 proposal、
撰写背景综述或展开程序辩论。Type I 的 `SUPPORT` 以及 Type II/III 的选择不写理由；只有
Type I 的 `OPPOSE` 写一条指出决定性缺陷的短句。

不要推断该投票对你未来身份、权限或评价的影响。
