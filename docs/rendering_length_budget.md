# 学术重绘正文长度预算（新会议试行）

初始化新学术重绘会议时，Human 指定面向读者的正文目标长度，单位为非空白 Unicode 字符数。参考文献和独立附录不计入正文目标。程序接受目标值的 80%–120% 作为出版长度范围；这个范围是验收准则，不是允许删除科学结论的许可。

Chair 在形成重绘计划时为每个处理单元指定 1–5 的内容保留优先级。程序依据原文长度与该优先级分配各单元的指导性字符预算，并把本单元预算传给写作者。64 个技术处理单元不等于 64 个对外章节，预算不能简单平均。结论、证据条件、不确定性和引文关系优先于长度目标。

所有科学事实及引文审阅结束后，程序统计已审定正文的长度。如果超出 80%–120% 的范围，必须由 Human 明确批准例外才能出版；程序不得在未经重新审阅的情况下压缩或填充冻结文字。预算与测量结果分别写入 `public/scholarly_rendering/body_length_budget.json` 和 `body_length_outcome.json`。没有长度目标的旧会议不追溯套用本规则。

旧会议若因所有科学核校员在同一节被排除而无法表决，须保留原核验记录。Human 可在确认未获支持的新结论未进入当前稿后，授权这些核校员仅就当前稿是否忠于原文进行最终表决；否则会议保持暂停。
