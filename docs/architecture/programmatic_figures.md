# 程序化学术配图（第一版）

文献调研的 v071/fast 学术主笔自动加载包内
`src/project_ensemble/assets/skills/academic_figures/SKILL.md`。不需新增图片供应商或上传本地图片。
这是可选写作能力；图确有帮助时主笔提交规格，没有数据或没有必要时只写正文。

主笔在 `draft.figures` 提交 JSON 规格，并在正文独占一行放 `[[FIGURE:id]]`。
固定 Matplotlib 绘图器支持折线、分组柱状、散点、热图、关系/流程示意。
它只接收有限数据和文字，不执行模型生成的代码、不下载外部图片、不读取用户图片路径。
数据图要求单位、数据依据和来源；示意图明确区分箭头的含义，不能当成定量或因果证据。

规格与正文一同科学审阅，审阅者核对数据和出处但不声称已目视检查图片。
fast 局部修订用 `figure_edits` 按 `figure_id` 和 `expected_figure` 定位，
`replacement` 提交完整修正规格，或用 null 删除图；失败修改只记单项诊断，仍交科学复核。
v071 最后的局部科学核查也覆盖仅修改图而没有修改正文的情况。

报告组装前把图注和文献出处纳入正文引文编号，图号全篇连续。
出版时将 PNG、SVG、作图规格、文件哈希保存在会议的 `public/final/figures/`。
总出版清单包含 `figure_manifest_path`。报告 Markdown 与同目录的 `figures/` 一起使用；
HTML 内嵌 PNG，可单文件传递；PDF 使用同一 PNG。默认主笔一章最多六张图。

格式不合法的可选图被单项省略，原始主笔响应与诊断保留；不会拒绝整章。
有效规格的绘制失败时，报告改为同数据的表格或关系文字，保留图注和出处，
失败记录也冻结，重启不重复绘制同一失败请求。科学异议不能因为技术省略而被标为通过。
既有冻结稿、已出版文件及旧稿的空字段序列化保持不变，不会自动补图或重写历史报告。
