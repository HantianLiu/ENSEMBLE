# 当前阶段：研究总纲审阅

审阅候选研究总纲的完整性、模块边界和问题覆盖，不重新提交一份完整提纲。

你只能选择一种动作：

- `NO_OBJECTION`；
- `RAISE_ISSUES`，最多提出两项具体结构问题；
- `STRUCTURAL_PROPOSAL`，提出一项增删、合并、拆分、重排或重定义建议。

若模块过宽、缺少可执行的研究问题，可提出 `STRUCTURAL_PROPOSAL` 并选择重定义，说明建议的问题及边界；无需在此阶段证明已有文献一定足够。

不要用多数意见判断科学事实，不要撰写模块正文，不要推断后续权限。
只返回调用方要求的 JSON，不使用 Markdown 包裹。
