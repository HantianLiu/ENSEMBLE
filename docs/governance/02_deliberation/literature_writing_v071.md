# 文献综述模块写作与科学审阅规则（v0.7.1 试行）

本规则只适用于初始化时冻结 `literature_writing_policy = "v071"` 的新文献报告会议。旧会议不迁移、不追溯改票；其既有模块研究、Research Desk 和证据包规则继续有效。本规则从每个模块的证据 dossier 冻结后开始，模块之间顺序推进。

## 模块提纲

轮值 Builder 根据模块任务和证据提交结构性提纲，不撰写正文。该四人组的 Monitor、Cartographer、Librarian 各投一票：第一稿三票全赞成通过；否则 Builder 读反对理由后写第二稿，第二稿至少两票赞成通过；仍未通过时形成第三稿，第三稿自动采纳。第二稿反对附言只作为主笔的非约束性建议。提纲不裁定科学真伪，也不得预写整章。

## 主笔与知识上下文

Human 初始化时单独选定学术主笔的模型和 reasoning effort。主笔不是第五种 Representative，不参与代表表决。同一主笔按模块顺序写作；人类更换模型时，以不可变运行时更换记录为界，只影响之后尚未冻结的调用。当前模块的输入包括已采纳提纲、本模块 dossier 和文献临时编号目录；跨模块仅给前面冻结模块的简短摘要和滚动术语表，不给前章全文。外部事实须经 Research Desk；主笔不得自行联网。临时文献编号 `C00001-00001` 的两段数字长度只是 ID 格式，不是文献价值或排序票数；正文出版时按首次出现顺序重新编排读者引文。

主笔记录新增术语是否需要数学定义；需要公式时同时给出公式、符号和适用条件，并在正文解释。术语只在模块正文冻结后纳入滚动表。主笔若认为后得证据质疑已通过提纲的某个讨论范围，须逐项提出对应提纲条目、证据包 ID 和理由；所有本会科学审阅智库长仅对该局部证据挑战投 YES/NO。赞成票超过有资格智库长人数的一半，仅表示挑战有效，不表决新科学结论。未过半时建议主笔维持原范围，但不强制。

## 两轮科学审阅

所有仍有资格的 Librarian Representative 各自密封提交对当前稿的局部科学问题清单；全部完成前不公开。每条异议必须指向当前正文中的一个片段和一项具体判断。Chair 按相同位置和相同被质疑命题归并，保存原始异议和提出者身份于审计层；公开意见仅用匿名标签。Chair 逐条选择交主笔回应或说明理由打回，不得自行新增科学结论。

被打回异议的救济票只由未提出该归并异议的智库长投，过半即要求主笔回应。若超过半数的智库长独立提出同一归并异议，救济自动通过；若既未自动通过又无合格投票者，由主笔投一张明确标记为程序性兜底的票。救济只决定是否应回应，不裁决真伪。主笔据第一轮意见返修，智库长阅读前轮清单与处置后再提交第二轮清单；主笔对第二轮获受理问题作最后返修。最后只对改动段落及相关证据作局部科学核查，不开启第三轮全文审阅。若局部核查仍有实质问题，暂停向 Human 呈递具体问题，可授权一次限域返修；再次发现问题须由 Human 决定是否带可见限制发表或暂停人工复核。

## 出版和可追溯性

科学问题处理后沿用确定性的引文、编号与格式校验。全篇导读由同一主笔根据冻结模块摘要撰写；摘要和引言属于快速导读，不替代正文的科学核查。结论如存在，由智库长作一次限域审阅，主笔只可据此局部修订。模块正文、原始票、归并依据、主笔版本及人类决定均不可覆盖。首次报告先交付；以后若 Human 要求重审，应建立带谱系的新记录，不改已发表冻结件。

本试行规则没有授予 Chair 把缺失票伪造成其他代表投票的权力。任何可能改变结果的关键缺票仍须显式暂停，直至 Human 或单独配置的授权流程处置。
