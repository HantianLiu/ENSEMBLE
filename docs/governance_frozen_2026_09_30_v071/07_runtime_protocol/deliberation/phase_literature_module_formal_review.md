# 文献模块：正式审阅

提交 `NO_OBJECTION`（无异议）或指向具体段落的实质问题。第一轮最多两项，第二轮最多一项决定性问题。不要另写替代全文；没有新证据时，不重复已经解决的问题。审阅窗口完成前，提交内容保持密封。

若只有措辞、分段或可读性建议，可写入可选 `style_note`；无异议票也可附。附言不是实质异议，不影响表决，也不要求下一轮写作者采纳或解释。

审阅时一并核对本章临时引文目录：正文的 `[Ca-b]` 应指向本章真实来源，所列证据包应有正文对应引注；单篇研究不得被写成领域共识。若来源目录不足以判断主张是否得到支持，应限定异议到具体句子与尚缺的证据，不得凭标题相似擅自合并两篇文献。
