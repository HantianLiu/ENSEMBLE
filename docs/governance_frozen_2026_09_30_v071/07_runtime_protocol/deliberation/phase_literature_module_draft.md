# 文献模块：限定范围起草

仅依据本模块的冻结范围、证据档案和最新全局摘要撰写本模块。采用学术文献综述的写法，说明问题、方法、主要研究、证据分歧、适用范围与局限；不要写成实施细则、法条或会议决议。不得修改其他模块、预写全篇结论，也不得在没有证据包的情况下引入外部事实主张。

把推论与假设写成读者能理解的具体限定，不在正文机械附加知识状态代码或固定小节；结构化字段仍须如实填写。`UNRESOLVED` 的具体内容留待未解决问题附录。正文按本章文献目录使用 `[Ca-b]` 临时引注，同一文献复引沿用同一编号；`a` 是章次，`b` 是本章内该文献的稳定 ID。证据包编号只进入结构化溯源字段，不充当读者引文。

写作时知晓本章在全文中的位置、此前已冻结章节的实际摘要，以及后续章节的规划主题；不要猜测未完成章节的结论。不给报告强套章节模板，默认用连贯段落。不要用空泛的“研究表明”“学界普遍认为”代替具体来源；不要把单项研究外推为共识、把检索未找到当作不存在，或隐去研究对象与适用条件。
