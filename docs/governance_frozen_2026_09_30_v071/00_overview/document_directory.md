# 文书目录与用途

## 00_overview
制度总览、文书目录、版本说明。

## 01_constitution
共同原则、身份防火墙、人类权力、模型与 Chair 选择。

## 02_deliberation
议事程序，包含：
- 总则；
- amendment；
- sequential amendment docket；
- Chair procedural rulings；
- Drafting Alignment；
- Consultative conversion；
- 细则；
- vote；
- meeting pause；
- minority/advisory material；
- post-meeting audit petition；
- finalization order。

`02_deliberation/literature_review_continuation.md` 定义从既有会议派生文献调研报告、
继承公共 Research Desk 资产、研究总纲、模块证据问答、模块审阅确认、全文综合、
无门槛发表和异议保留的完整试行程序。

## 03_roles
完整角色规范。不得整体注入单个 Representative。

`03_roles/research_librarian.md` 定义共享、无表决权的 Research Desk：claim 规范化、
对抗性外部检索、evidence packet、freshness cache 与审计隔离。

CLI 的 research-only session 是 Research Desk 的无表决查询入口，不增加正式会议类型或
参与者角色。

## 04_think_tank
Librarian Think Tank 的知识完整性检查。

## 05_audit_conference
政协/审计会议的独立发掘、共享分析、有限自由讨论、final opinions 和 Chair synthesis。

## 06_execution_interface
面向人类的灵活移交接口。当前不定义独立代码交付会议，也不假设自主 Implementation Agent。

## 07_runtime_memory
角色专用 runtime memory，严格隔离。

## 08_schemas
建议的机器可读记录结构。

## 09_access_control
访问矩阵与上下文加载约束。

## 10_open_questions
尚未定案、不得由实现者自行猜测补全的问题。

## 反博弈与阶段化运行

`01_constitution/anti_gaming_firewalls.md`：完整反博弈原则。

`01_constitution/ballot_secrecy.md`：co-sponsorship freeze、sealed ballot 与禁止 rolling tally。

`07_runtime_protocol/`：Representative 实际可见的 stage-local protocol surface。Representative 不读取完整 deliberation protocol。


## Strategic-Behavior Audit

`05_audit_conference/strategic_behavior_audit.md` 定义审计层如何检查规则套利、适应性博弈、隐藏激励的副作用，以及相关机器记录。
