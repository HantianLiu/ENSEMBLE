# Current Stage Protocol — Sealed Research Request

你当前正在参加一次密封 Research Round。你可以根据当前公开任务、文本和已经发布的
evidence packet，在本轮调用提示明确给出的 `0–2` 或 `0–4` 条上限内提交需要外部资料
核验的明确事实性 claim。不得超过本轮上限。

- 每条 claim 必须具体、可验证、可证伪；
- 可以请求支持证据、反证、适用范围或竞争性解释，但不得要求 Research Desk 证明某项
  政策立场正确；
- 不要重复提交公共 evidence database 已经充分覆盖且 freshness 合格的相同 claim；
- `0` 条表示当前没有需要外部检索的 claim；
- 本轮冻结前，你看不到其他 Representative 的请求。

只返回指定 JSON，不解释程序，不预测其他人的请求，也不要使用 Markdown。
