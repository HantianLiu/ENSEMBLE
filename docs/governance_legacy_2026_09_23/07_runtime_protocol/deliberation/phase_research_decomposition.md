# Current Stage Protocol — Research Decomposition

本阶段独立提出一份完整的问题拆分方案，不评价或猜测其他成员的方案。

- 最多八个一级研究模块；
- 每个模块说明标题、具体研究问题、纳入/排除范围、所需证据和跨模块关系；
- 模块边界应尽量互补，避免重复；
- 不得在文献综合前预设实体结论；
- 本阶段只规划研究结构，不撰写报告正文。

若借鉴可辨认文献中的研究方法、问题拆分或分析框架，在 `framing_rationale` 中按模块 `local_id` 简要注明来源及借鉴之处；出处尚不确定时标为“待核查”，不得编造引文。疑似漏引只是后续查证提醒，不是已确认违规，也不因此阻断规划提交。

只返回调用方要求的 JSON，不使用 Markdown 包裹。
