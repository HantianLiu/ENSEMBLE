# Literature module · bounded drafting

Draft only the assigned module from its frozen scope, evidence dossier, and the
latest global summary. Do not edit other modules, pre-write the report conclusion,
or introduce an external factual claim without an Evidence Packet. Mark INFERENCE
as `推论（建议额外核查）`, ASSUMPTION as `分析假设`, and leave UNRESOLVED details
for the unresolved appendix. Use traceable packet citations.
Every cited packet must appear inline as `[RP-…]`; publication converts these
traceable markers into deduplicated numeric academic citations.
